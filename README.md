# Dart Basics

Learning project covering Dart fundamentals:

- var, final, const
- Types: int, double, String, bool
- Conditionals: if / else if / else
- Loops: for, while, do-while
- Functions: sum(int a, int b)
- Recursion: factorial(int n)
- Algorithms: isPrime(int n)

## Run

    dart main.dart
